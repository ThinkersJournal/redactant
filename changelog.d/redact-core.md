Adds the hand-written half of field-level redaction (`docs/DERIVE.md` slice 1, ROADMAP row 6; no derive macro yet). A record implements `Redact::describe_at` and reports each field to a `Sink` as `Disposition::Redacted`, `Disposition::Fingerprint` (keyed, from `Context::fingerprint`; no key means `Redacted`, never a bare hash) or `Disposition::Kept`, which only accepts a type implementing the marker trait `Keep` (never `Secret<T>`; under feature `serde` a `Keep` type must also be `serde::Serialize`, via `erased-serde`, now an optional dependency of that feature). `Context` can carry a caller-supplied key id. `Redact` is implemented for `Secret<T>`, `Fingerprint`, `&T`, `Box<T>`, `Option<T>`, slices, arrays and `Vec<T>` (index path segments); `x.redacted()` / `redacted_with(cx)` return a deterministic `Display`/`Debug` view. `FingerprintKey::tag(&[u8])` is new and `Secret::fingerprint` now calls it. All additions; `Disposition` and `Segment` are `#[non_exhaustive]`. Verified by canary tests D1-D5 with a negative control each (`tests/redact_canary.rs`), a compile-fail case that `Kept(&Secret)` is refused with a passing twin, and the existing suites unchanged. `cargo semver-checks` 0.51.0 against 0.1.2 passes (202 checks pass, 58 skip; no semver update required) with default features and with `--features serde`.
